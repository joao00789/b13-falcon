# Ícones Lucide usados no menu flutuante

SVGs de origem baixados do repositório público [lucide-icons/lucide](https://github.com/lucide-icons/lucide), diretório `icons/`.

Os SVGs ficam nesta pasta como arquivos de origem. Como o Android não renderiza SVG diretamente como drawable, o overlay usa vetores Android equivalentes em `android/app/src/main/res/drawable/ic_lucide_*.xml`.

Lucide é distribuído sob a licença ISC; o texto integral está em [LICENSE](./LICENSE). Ícones usados: `play`, `pause`, `square`, `brush`, `settings-2`, `palette`, `pencil`, `circle`, `undo-2`, `trash` e `x`.
